# Sitio raíz — Sebastián Elgueta Godoy

Paquete estático listo para publicar en `https://selguetagodoy.github.io/`.

## Publicación

1. Crear el repositorio público `selguetagodoy.github.io` en la cuenta de GitHub.
2. Copiar el contenido de esta carpeta a la raíz del repositorio.
3. Activar GitHub Pages desde la rama `main` y la carpeta raíz.
4. Verificar `robots.txt`, `sitemap.xml`, los enlaces internos y los datos estructurados.
5. Enviar el sitemap a Google Search Console y Bing Webmaster Tools después de la publicación.

El paquete no incluye fotografías ni identificadores que no hayan sido verificados. La carpeta está preparada con 19 URLs internas semánticamente diferenciadas, además de enlaces a los activos externos existentes.
