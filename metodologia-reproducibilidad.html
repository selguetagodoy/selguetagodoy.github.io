PRINCIPIO

No completar lo que la evidencia no permite completar.

Un vacío de información no se transforma automáticamente en una estimación. Cuando una observación no está disponible, permanece como dato faltante salvo que exista una metodología explícita y reproducible que autorice una derivación.

Del mismo modo, una nueva publicación no reemplaza silenciosamente una observación histórica. Las versiones, universos estadísticos y rupturas metodológicas se preservan para que las comparaciones sigan siendo auditables.

ESTÁNDAR COMÚN
01 · Fuentes

Jerarquía de evidencia

Se priorizan fuentes primarias, oficiales y técnicamente autoritativas. Registros secundarios pueden orientar la búsqueda, pero no sustituyen una fuente original disponible.

02 · Universos

Comparar solo lo comparable

Geografía, periodo, unidad, población y universo estadístico se mantienen explícitos. Cambiar alguno de estos elementos puede producir una ruptura de serie.

03 · Transformaciones

Observado, derivado y proxy

Una observación publicada no se presenta como equivalente a un cálculo derivado o a un proxy. Las transformaciones deben poder reconstruirse a partir de insumos identificables.

04 · Versionamiento

GitHub y Zenodo cumplen funciones distintas

GitHub refleja el estado operativo del proyecto. Zenodo conserva snapshots citables. Cuando una versión de GitHub es más nueva que la última versión archivada, esa diferencia se declara expresamente.

05 · Trazabilidad

Metadatos y fuente de verdad

Cada repositorio publica Source of Truth, CFF, BibTeX, CodeMeta, Data Package, changelog, notice y reglas de contribución basadas en evidencia.

06 · Correcciones

Corregir sin borrar la historia

Las correcciones identifican fuente, periodo, universo, unidad, campo afectado y efecto sobre comparabilidad. Cada repositorio expone un formulario Evidence-backed correction; los cambios materiales se canalizan mediante una nueva versión en lugar de reescribir silenciosamente una snapshot.

07 · Interoperabilidad

Data Package y RO-Crate 1.2

Cada proyecto declara sus recursos públicos en un Data Package y los describe además como un objeto de investigación RO-Crate 1.2, conectando archivos, autor, DOI, landing y metadatos sin incorporar material privado.
